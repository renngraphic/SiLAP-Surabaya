# Glossary — SiLAP Surabaya

| Term | Meaning (in this project) |
|---|---|
| **SiLAP Surabaya** | Product name for the UI-only prototype. Stands for *Sistem Laporan Aparat*; used as the visible brand on all four screens. |
| **Laporan** | A traffic-violation report created by a civilian. Identified by a public report code. |
| **Kode Laporan** | Human-readable reference, format `SILAP-2026-000417`. Generated by the UI on submit and used instead of an account to look up status. |
| **Pelapor** | Civilian who sees and submits a violation. May be anonymous; contact is optional and never required. |
| **Petugas** | Government officer using the internal dashboard. Two named actors appear: **Dishub** (verifies and forwards) and **Polrestabes Surabaya** (acts on the violation). |
| **Bukti** | Photo evidence attached to the report. In the prototype only the file name and a local preview are kept; nothing is uploaded. |
| **Kategori pelanggaran** | One of six fixed options: lampu merah, helm, parkir liar, lawan arah, putar balik ilegal, kecepatan berlebih. |
| **Patokan** | Free-text landmark that complements the Surabaya district, e.g. "depan Mall Tunjungan Plaza". |
| **Status** | Current stage of a report. See `domain-model.md` for the allowed transitions. |
| **Diterima** | Initial status. The report exists but has not been checked. |
| **Diverifikasi** | Dishub has checked the report and considers it valid. |
| **Ditindaklanjuti** | Polrestabes has acted (e.g. ticket, warning, towing). Requires a proof note. |
| **Selesai** | Terminal status. The action is closed and the proof is visible to the reporter. |
| **Ditolak** | Terminal status. Report rejected during verification; requires a reason. |
| **Bukti tindak lanjut** | Officer-supplied note describing the government action. Shown on the public status screen as accountability. |
| **Demo data** | Pre-seeded reports used to make the prototype presentable without a backend. |
